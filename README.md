# Training Session Booking

Primitive, layered web application (see [draft architecture.md document](docs/architecture.md)), that imitates
how an end-user books a training session, developed as part of Server Side Web Development module, MTU in order to get familiar with
process of full-stack web development using Express, EJS templating, Mongoose ODM, etc.


# Requirements

* [node.js](https://nodejs.org/en)
* [npm](https://www.npmjs.com/)

> [!IMPORTANT]
> [Node Version Manager (aka nvm)](https://github.com/nvm-sh/nvm#installing-and-updating) is crucial, use it to install latests versions of both node.js and npm.

# Quick Start

1. **First**, *clone this repository* inside of desired folder using [git](https://git-scm.com/):

```
git clone https://github.com/tekisho/training-session-booking
```

2. **Then**, *resolve and download all dependencies* using [npm](https://www.npmjs.com/):
```
npm install
```

3. **Finally**, *run application* using `package.json` script:
```
npm start
```

> [!NOTE]
> Use `npm run dev` script during development to automatically re-run (check [nodemon](https://www.npmjs.com/package/nodemon) package) web-server each time you modify source code.
